VoiceAgent Shortcut

Build this once in the Shortcuts app (about 15–20 min). Then a floating button over every app lets you speak a command.

You need your Groq API key (console.groq.com/keys). Open this page on the iPhone and switch between Safari and Shortcuts while you build. To add an action: tap + / the search bar at the bottom of the shortcut editor and type the action name in bold.

1. Create the shortcut

Shortcuts app → + (top right) → tap the name at the top → rename to VoiceAgent.

2. Add these actions, in order

  1. Dictate Text — tap the arrow ▸ and set Stop Listening to After Pause.
  2. Replace Text — Find " → Replace with ' → in Dictated Text.
    Stops a quote in your speech from breaking the request.
  3. Current Date
  4. Format Date — Date Format: ISO 8601, Include Time: on.
  5. Text — paste the request body below (use the Copy button). Then inside it:
    • select the word COMMAND_HERE (keep the quotes around it) → delete it → tap Updated Text in the variable bar above the keyboard;
    • select NOW_HERE → delete it → insert Formatted Date.
  6. Get Contents of URL — URL: https://api.groq.com/openai/v1/chat/completions
    tap ▸ (Show More):
    • Method: POST
    • Headers → Add new header: Authorization = Bearer gsk_your_key_here (the word Bearer, a space, your key)
    • Add new header: Content-Type = application/json
    • Request Body: File → tap File → choose the Text variable (from step 5)
  7. Get Dictionary Value — Get Value for choices in Contents of URL.
  8. Get Item from List — First Item from Dictionary Value.
  9. Get Dictionary Value — Value for message in Item from List.
  10. Get Dictionary Value — Value for content in Dictionary Value.
  11. Get Dictionary from Input — input: Dictionary Value.
  12. Set Variable — name Reply, input Dictionary.
  13. Get Dictionary Value — Value for type in Reply.
  14. Set Variable — name Type, input Dictionary Value.

3. Add one “If” block per task

Add If, set it to Type is the word shown. Put the actions between If and End If. You can delete the empty Otherwise line. Add the blocks one after another (not inside each other).

If Type is open
  1. Get Dictionary Value — url in Reply
  2. Open URLs — Dictionary Value
If Type is timer
  1. Get Dictionary Value — minutes in Reply
  2. Start Timer — for Dictionary Value minutes
If Type is reminder
  1. Get Dictionary Value — title in Reply → Set Variable Title
  2. Get Dictionary Value — due in Reply → Set Variable Due
  3. Add New Reminder — text: Title; tap ▸, turn on Remind Me → At Time → Due
If Type is message
  1. Get Dictionary Value — to in Reply → Set Variable To
  2. Get Dictionary Value — text in Reply → Set Variable Body
  3. Send Message — Body to To; tap ▸ and keep Show When Run ON
    Keep this on: it lets you check the message and recipient before anything is sent.
If Type is flashlight
  1. Set Flashlight — tap “Turn” and change it to Toggle

4. Last action (after all the If blocks)

  1. Get Dictionary Value — message in Reply
  2. Show Notification — Dictionary Value

This shows what it did, or the answer to a question.

5. Test it

Tap ▶ in the editor and say “Open YouTube”. On first run iOS asks permission: allow speech recognition, and Always Allow connecting to api.groq.com. Then try “Set a timer for 2 minutes”, “Remind me to call Mom tomorrow at 9”, “Search YouTube for history of Rome”, “Turn on the flashlight”.

6. Floating button over every app

AssistiveTouch: Settings → Accessibility → Touch → AssistiveTouch → On → Custom Actions → Single-Tap → scroll to Shortcuts → VoiceAgent.

Drag the floating button to a screen edge. Tap it inside any app and speak.

Also available:
  • Action Button (iPhone 15 Pro and later): Settings → Action Button → Shortcut → VoiceAgent
  • Back Tap: Settings → Accessibility → Touch → Back Tap → Double Tap → VoiceAgent
  • Siri: “Hey Siri, VoiceAgent”

If something goes wrong

  • Error at a “Get Dictionary Value” step: Groq replied with an error. Add Quick Look right after Get Contents of URL to see it. Invalid API Key means the Authorization header is wrong (it must be Bearer + space + key).
  • “model … does not exist”: Groq retired the model. In the Text action, change openai/gpt-oss-120b to a current model from console.groq.com/docs/models.
  • Nothing happens for an app: the app may not be installed; the answer notification will still say what it tried.

Your API key is stored inside this shortcut. Don't share the shortcut with anyone.

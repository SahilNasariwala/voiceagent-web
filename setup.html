VoiceAgent — 5-minute setup

Paste one script, add one shortcut action, done.

1
Install Scriptable (free) from the App Store.
Open App Store
2
Copy the script:
3
Open Scriptable → + → paste → tap the title at the top and name it VoiceAgent → Done.
Tap the script once to run it: paste your Groq key (console.groq.com/keys) when asked, allow the microphone and speech recognition, then (if the mic screen stays blank) type Open YouTube in the box that appears.
4
Shortcuts app → + → name it VoiceAgent, then add two actions:
① Dictate Text — tap ▸, set Stop Listening to After Pause.
② Run Script (Scriptable) → choose VoiceAgent → tap ▸: turn on Run In App, and set Texts to the Dictated Text variable (tap Texts → Select Variable → Dictated Text).
Already made the one-action version? Just add Dictate Text above Run Script and set Texts as above.
5
Floating button: Settings → Accessibility → Touch → AssistiveTouch → On → Custom Actions → Single-Tap → VoiceAgent.
Or: Action Button → Shortcut → VoiceAgent · Back Tap → Double Tap → VoiceAgent · “Hey Siri, VoiceAgent”.
Try: “Search YouTube for history of Rome” · “Directions to the airport” · “Set a timer for 10 minutes” · “Remind me to call Mom tomorrow at 9” · “Text Mom I'm on my way” (you confirm before it sends) · “Run my workout shortcut”.

Say “reset key” to change your API key. The key is kept in the iOS Keychain, not in the script.
